# fastsw-proxy
A extremally lightweight web proxy using 2 files, a frontend and a Service Worker
site support
YouTube (partial)
Google (full)
Discord (full)
TikTok (full)
and more!
its powered by libcurl.js and wisp so any existing wisp server will work file see example_frontend.html for a exmaple fastsw frontend
fastsw.all.js is just raw code and dist/fastsw.js is the minifed bundle you shuld actually use for prod and proxy websites, index.html is just another styled fastsw frontend not needed at all
